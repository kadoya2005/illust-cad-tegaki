# イラレCAD 手描き（試作）

タブレットのペンで描いた線から立体をつくるアプリです。
iPad の Safari と Apple Pencil で使えるようにするのが目標です。

- 正面・側面などの向きで、手描きで閉じた線を描く → 厚みを付けて立体にする
- 視点を回して、別の向きにも描く
- 閉じていない線を押し出すと、リボンや壁のような薄い面になる
- その先：断面どうしをつなぐロフト、Flash のように描いて動かすアニメーション

[イラレCAD 3D](https://github.com/kadoya2005/illust-cad-3d)（ver 41、2026-11-26）を土台にして、別のアプリとして始めました。
三面図・押し出し・折りたたみ・STL 書き出しなどは、そのまま入っています。保存形式 `.icad` は 3D 版と同じなので、ファイルを行き来できます。
これからやることは [進捗と予定.md](進捗と予定.md) にあります。

Adobe Illustrator とは関係のない、非公式のツールです。

**すぐ試す：https://kadoya2005.github.io/illust-cad-tegaki/** （ブラウザで開くだけ。インストール不要）
**iPad 入力テスト：https://kadoya2005.github.io/illust-cad-tegaki/ipad-test.html** （ペン・指・手のひらの区別、手描き線のベジェ化を試すページ）

## 鉛筆ツール（N）（ver 2）

- ツールバーのペンの下の鉛筆（ショートカット N、イラレと同じ）。ドラッグで自由に描き、離すとベジェ曲線のパスになる（取り消しは一筆で 1 回）
- **始点の近くで離すと閉じる**：一度は始点から画面で 30px 以上離れて、終点が始点から 10px 以内のとき。そのとき「離すと閉じる」と出る
- 閉じた線は塗りあり（いまの塗りと線の色）、開いた線は線だけ
- **正面図・側面図でも描ける**（真正面・真横のとき。回して見ているときは描けない）。ペンと同じ作業平面に置かれ、パネルの「3D 押し出し」で厚みを付けると立体になる
- **なめらかさ**：鉛筆ツールのボタンをダブルクリック（または環境設定 Ctrl+K）。画面で何 px までずれてよいか（初期値 1px）。大きいほどアンカーが減る。0 にすると当てはめずに点のまま
- 描いている途中で中断された（ほかの窓に切り替わった・Esc・ペンが取り上げられた）ときは、その一筆を捨てる
- 描いている間は、ほかの指や手のひらが触れても無視する

以下は、土台にした 3D 版から引き継いだ説明です。

- 画面左上のタイトルの横に「ver ○○」が出ます（このアプリは ver 1 から。いまは ver 2）。古い番号のままなら Ctrl+F5 で読み込み直してください
- 自動テスト：アドレスの最後に `?test` を付けて開くと、折りたたみ・保存・単位などの試験を流して結果を右下に出します（書類は変えません）
- 折りたたみのお試し用：[samples/立方体の展開図.svg](samples/立方体の展開図.svg) を保存して「開く」で読み込む

## 使い方

`index.html` を Chrome か Edge で開くだけで動きます（インストール不要）。

- **保存（Ctrl+S）は `.icad`**：このアプリの作業用の形式です（中身は JSON）。ガイドや、3D で使う ID もそのまま残ります
- **STL 書き出し**：押し出した立体を 3D プリンター用の STL（単位 mm）にします。選んでいればそれだけ、選んでいなければ全部
- **SVG 書き出し（Ctrl+Alt+E）**：Illustrator で開ける SVG にします。レイヤーは `<g data-name>` で書き出します
- Illustrator で書き出した SVG も「開く」で読み込めます。SVG を開いたときは、Ctrl+S でその SVG に上書きします
- SVG ファイルを画面にドロップすると、いまのレイヤーに配置します
- コピーすると SVG のテキストとしてクリップボードに入るので、Illustrator に貼り付けられます（未確認）
- 作業中の内容はブラウザに自動で残ります（次に開いたときに復元）

## できること

### 3D（段階1）
- 画面は三面図：左が **平面図**（いつもの 2D の画面）、右上が **正面図**、右下が **側面図**（右から見た図）
- 閉じたパスを選んで、パネルの「3D 押し出し」で **高さ** と **底**（床から浮かせる高さ）を入れると立体になる
- **どの図でも選べて、選んだものはどの図にもバウンディングボックスが出る**（立体も、床の上の線も）
- 正面図・側面図（真横から見ているとき）：枠の中をドラッグで移動（正面図＝左右と高さ、側面図＝奥行きと高さ）、取っ手で伸び縮み（横＝幅・奥行き、縦＝高さ）。Alt で中心から、Shift で縦横比そのまま（移動では真横・真上に）。平らなパスの上の取っ手を引き上げると押し出し。高さはほかの立体の上・下に吸着（Ctrl で吸着しない）
- 正面図・側面図の操作：平面図と同じく Space＋ドラッグ（手のひら）、Ctrl+Space＋クリック（拡大、Alt で縮小）、ズームツール（Z）・手のひらツール（H）、Alt＋ホイールで拡大・縮小
- **Shift＋Space＋ドラッグで回して見られる（3D 手のひら）**。ドラッグ中に Shift を押していると 15° ずつ。ダブルクリックで正面・側面に戻る（Ctrl+0 で全部戻る）
- 正面図・側面図は 表示 → 正面図・側面図 でしまえる
- 押し出しは、コピー・複製・保存（.icad と SVG）でそのまま付いてくる（イラレで開いて保存すると消えます）

### 2D

- ペン、ダイレクト選択、アンカーの追加・削除・切り替え
  - ペン：ドラッグ中に Alt で切り返し（鋭角）、Space でアンカーを移動、Alt でアンカーポイントツールに一時切り替え
  - ダイレクト選択：曲線の線をドラッグで形を変える、Delete でその線だけ消す
- 長方形、楕円形、直線、回転、リフレクト（折り返し）、拡大・縮小、スポイト
  - 回転・リフレクト・拡大縮小は、クリックで基準点、離すときに Alt でコピー、Alt+クリックで数値入力（イラレと同じ）
- 移動（Enter で数値入力）、Alt ドラッグで複製、変形の繰り返し（Ctrl+D）、平均（Ctrl+Alt+J）
- グループ（Ctrl+G）、連結（Ctrl+J）、複合パス（Ctrl+8）、重ね順、ロック、隠す
- パスファインダー：合体、前面オブジェクトで型抜き、交差、中マド、分割、刈り込み、背面オブジェクトで型抜き
- 整列：揃える・分布・等間隔に分布（選択範囲／キーオブジェクト／アートボード基準）
- パスのオフセット（マイター・ラウンド・ベベル）
- 定規（Ctrl+R）とガイド、グリッド（Ctrl+@）、スマートガイド（Ctrl+U）
- レイヤー（表示／ロック／並べ替え／名前変更）
- 塗りと線、線幅、アウトライン表示（Ctrl+Y）、環境設定（Ctrl+K：矢印キーで動く量）

ショートカットの一覧はアプリの「ショートカット一覧」ボタン（F1）で見られます。

## まだできないこと

- 文字、画像、グラデーション（読み込むときは飛ばします）
- シェイプ形成ツール、ライブコーナー、パスの単純化
- 3D の続き：3D バケツ、回転体
- Ctrl+N・Ctrl+W・Ctrl+T（ブラウザが使っているキーなので取れません）

## プログラムの構成

ビルドなしで `file://` でも動くように、ふつうの `<script>` を決まった順で読み込んでいます（順番は `index.html` に書いてあります）。

公開している版（GitHub Pages）を更新するときは、`index.html` の `?v=番号` を1つ増やします。ブラウザに残った古いファイルを使わせないためです。

### データの形（`.icad`）

```
doc = {
  version: 3, units: 'mm', width, height,
  guides: [{ axis: 'x' | 'y', v }],
  layers: [{ id, name, color, visible, locked, items: [パス or グループ] }],
  solids: []   // 3D の形を置く場所（断面はパスの ID で参照。レイヤーとは別に持つ）
}
パス     = { id, subs: [{ nodes: [{ x, y, hin, hout, smooth }], closed }], fill, stroke, sw, rule, hidden, locked, x3d? }
           x3d = { z0: 底の高さ, h: 高さ }（押し出したパスだけ）
グループ = { id, type: 'group', name, children: [...], hidden, locked }
```

- 座標の単位は mm（線の太さも mm）。Illustrator とのやりとり（SVG の読み書き・コピペ）のときだけ pt に換算します。前の版の .icad（pt）は開くときに mm に直します
- 3D の向き：平面図の x が右、平面図の下（y が大きい方）が手前、z が上
- ハンドル `hin` / `hout` は絶対座標。`null` はハンドルなし
- ID は保存・読み込み（`.icad` でも SVG の `data-icad-id` でも）で変わりません
